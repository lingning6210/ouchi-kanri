# おうち管理 🐼

家事を定期タスクとして管理し、買い物リストと連携させる家族向けアプリです。竹＆パンダのカレンダーUIをイメージして作られています。

## 起動方法

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # 本番ビルド
npm run preview  # ビルド結果をプレビュー
```

React + Vite 製。データはブラウザの localStorage に保存されます。

## 主な機能

- **カレンダー**：1ヶ月が1画面に収まり、各日にタスクのタイトルを色付きで表示。今日をハイライト、完了は取り消し線。日をタップすると詳細シートで完了チェック（将来の予定も前倒しで完了可能）。
- **ToDo**：今日のタスク＋未完了（オーバーデュー）を「自分」「みんな」に分けて表示。
- **買い物リスト**：手動追加に加え、家事完了時の消耗品確認から自動追加。
- **消耗品の連携**：タスクに消耗品を紐付け。完了時に「まだある / もうない」をポップアップで確認し、「もうない」なら買い物リストへ自動追加。
- **柔軟な繰り返し設定**：`なし / 毎日 / 毎週 / 毎月 / 毎年`、間隔（Nごと）、終了日、毎週の曜日指定、毎月の「日付基準 / 第N曜日基準」に対応。
- **オーナー＆代行報酬**：タスクに担当者を設定。他の人が代行するとカウントされ、しきい値に達するとリクエスト（例：お菓子買ってきて）が発生。
- **通知時刻の設定**（その他タブ）。
